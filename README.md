## 🏗️ Application Structure

### Core Components:
- **User Name Input** — stored in LocalStorage for personalized access  
- **Main Menu** — welcome screen with game introduction and a “Start” button  
- **Game Screen** — area with word cards, hint options, sentence construction, and round navigation  
- **Statistics Page** — detailed round summary, sentence review, audio playback, and artwork display  

### Game Mechanics:
- **Difficulty Levels & Rounds** — 6 levels of difficulty and multiple rounds  
- **Sentence Construction** — drag-and-drop interface for assembling correct sentences  
- **Hints** — translation, pronunciation, and visual puzzle clues  
- **Artwork Puzzle** — each correctly assembled sentence reveals a piece of the artwork  
- **Progress & Results** — view performance stats and progress after each round  

## 🔧 Installation and Setup

1. Clone the repository

```sh
  git clone https://github.com/lustrochka/rss-puzzle.git
```

2. Install NPM packages

```sh
  npm install
```

3. Start project

```sh
  npm run start
```
